01 / GAME OVERVIEW

어떤 게임인가요?

세 명의 플레이어가 기계 다리가 달린 집을 함께 운반합니다.
운전·수리·자원 수집으로 역할을 나누며 목적지로 이동하는 협동 경험을 목표로 하는 2인 팀 프로젝트입니다.

  • 3인 플레이어의 역할 분담과 협동

협동 플레이를 위한 담당 영역과 목표

01
담당 영역 · 목표 포함

캐릭터·상호작용

캐릭터 조작, 상호작용, 도구 장착과 애니메이션 시스템.

02
담당 영역 · 목표 포함

멀티플레이

NGO 기반 동기화와 Steam P2P 연동.

03
담당 영역 · 목표 포함

집과 협동 시스템

집 운전·상태 관리·수리와 물리 기반 협동 시스템.

거리 기반 보이스 채팅과 무전기를 개발 목표로 두고 있습니다. 사용 라이브러리와 구현 상태는 미공개입니다.

05 / DEVELOPMENT & PROBLEM SOLVING

한 채의 집, 여러 플레이어의 상호작용

맥락
운전·수리·자원 수집이 하나의 집을 중심으로 이어지는 협동 플레이를 목표로 합니다.
접근
캐릭터 상호작용, 집 상태 관리, 온라인 동기화를 담당 개발 영역으로 정리했습니다.
구체적인 권한 구조와 데이터 흐름은 아직 공개되지 않았습니다.
현재 결과
현재 개발 진행 중입니다.
해결된 오류나 검증된 개선 성과는 자료를 확인한 뒤 추가할 예정입니다.
